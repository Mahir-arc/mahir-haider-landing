# Mahir AI Video Studio

An isolated starter app for creating short-form video scripts and storyboards with OpenRouter.

## Safety
- This project lives on `feature/mahir-ai-video-studio`, not `main`.
- It does not change the portfolio site's deployed branch.
- Never commit a real API key. Set `OPENROUTER_API_KEY` only in hosting environment settings.
- The server will allow only explicitly free model IDs ending in `:free`; no paid fallback.

## Status
Starter project scaffold. Hosting and secure secret configuration are still required before generation can run.
